### Script for installing vmware workstation kernel module on latest kernel 

##### After 25H2

    curl -fssL https://raw.githubusercontent.com/arfshl/vmware-module-installer/refs/heads/main/linux/after25/install.sh | bash

##### Before 25H2

- Player

      curl -fssL https://raw.githubusercontent.com/arfshl/vmware-module-installer/refs/heads/main/linux/pre25/player.sh | bash

- Workstation

      curl =fssL https://raw.githubusercontent.com/arfshl/vmware-module-installer/refs/heads/main/linux/pre25/workstation.sh | bash
